# تحلیل مکانی (Suitability Analysis) برای مکان‌یابی بیمارستان در شهر تهران

در این جلسه به **Suitability Analysis** با ذکر یک مثال به منظور مکان‌یابی بیمارستان در شهر تهران می‌پردازیم.  
مراحل مکان‌یابی شامل موارد زیر است:

1. تعریف معیارها  
2. امتیازدهی به معیارها  
3. وزن‌دهی به معیارها  
4. روی‌هم‌گذاری (Overlay) آن‌ها

---

## معیارها

در این بخش، معیارهای ما عبارت‌اند از:

- فاصله از بیمارستان‌های موجود  
- نزدیکی به پارک‌ها و فضاهای سبز  

---

## آماده‌سازی داده‌ها

داده‌های مورد نیاز را از **OpenStreetMap** دانلود کرده و از قسمت **Downloads** در صفحه جدید از **QGIS** باز می‌کنیم.

- از گزینه **SELECT FEATURE BY VALUE** برای انتخاب بیمارستان‌های موجود استفاده می‌کنیم  
  (در قسمت `OTHER TAG`، عبارت `HOSPITAL` را می‌نویسیم).  
- برای پارک‌های موجود نیز همین روش را انجام داده و خروجی آن را به‌صورت **Shapefile** ذخیره می‌کنیم.  
- هنگام خروجی، حتماً به مختصات دقت شود (`EPSG:32639` باید بررسی شود).  

سپس نقاط به‌دست‌آمده را باید به **Raster** تبدیل کنیم.

---

## تبدیل Vector به Raster

**مسیر:**  
`Processing → GDAL → Vector to Raster`

**نکات مهم:**  
- `Fixed Value = 1`  
- `Width & Height Resolution = +10`  
- `Output Data Type = INT16`  
- حتماً `Output Raster Size Unit = Georeferenced Units` باشد.  
- مقدار `Extent` را برای هر دو لایه به‌صورت یکسان وارد کنید.  

برای هر دو معیار این کار انجام می‌دهیم و نام لایه‌ها را اصلاح می‌کنیم.

---

## محاسبه فاصله تا عوارض (Proximity)

**مسیر:**  
`Processing → GDAL → Raster Analysis → Proximity`

در این مرحله:  
- لایه مورد نظر را انتخاب می‌کنیم.  
- `Distance Unit = Georeferenced Units`  
- `Output Data Type = INT16`  

---

## امتیازدهی به معیارها (Reclassify)

**مسیر:**  
`Processing → Raster Analysis → Reclassify by Table`

- لایه مورد نظر را انتخاب کنید.  
- از قسمت **Reclassification Table**، امتیازدهی را انجام دهید.  

---

## وزن‌دهی به معیارها (Raster Calculator)

در پایان به قسمت **Raster Calculator** رفته و به معیارها وزن می‌دهیم.  
(توجه: مجموع وزن‌ها باید برابر با **۱** باشد.)
